# ARXH Graphics

A bold, editorial-style portfolio website designed for graphic designers,
creative directors, visual artists and independent studios.

The website uses a dark visual system with acid-lime accents,
oversized typography, asymmetric layouts and subtle motion.

---

## ✦ Live Demo

After enabling GitHub Pages, your website will be available at:

https://ARXH-Graphics.github.io/graphic-designer-portfolio/

Replace `ARXH Graphics` with your GitHub username.

---

## ✦ Features

- Responsive portfolio design
- Editorial / art-direction aesthetic
- Large typography
- Dark + acid-lime visual identity
- Animated marquee
- Animated hero element
- Project showcase
- About section
- Services section
- Contact CTA
- Mobile responsive layout
- No frameworks required
- No build tools required
- GitHub Pages compatible

---

## ✦ Tech Stack

HTML5  
CSS3  
JavaScript  
Google Fonts

No React, Node.js or build process is required.
